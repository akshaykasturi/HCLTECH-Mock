Service levels and status page

NovaPay targets 99.9% monthly availability for every production route, measured at the gateway.

Latency objectives

  • Read routes (GET): p95 under 300 ms.
  • Order and refund creation: p95 under 1000 ms.
  • Payments: p95 under 1500 ms, because the external bank gateway adds latency.

Error budget

An endpoint error rate above 5% for 5 consecutive minutes opens an incident. Client errors (4xx except 429 during an incident) do not count against the budget.

Incident communication

Incidents are posted on the status page within 10 minutes with the affected routes and dependencies. Merchants should quote the X-Correlation-Id of failing requests when contacting support.
